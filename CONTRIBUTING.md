# Contributing

This repository is a Trida AI reference blueprint: a working prototype
that demonstrates an architecture, not a product under active feature
development. Contributions that sharpen the demonstration are welcome:

- **Issues** — report setup problems, doc gaps, or behaviour that
  contradicts the README/architecture docs. Include your OS, Python
  version, and the exact command you ran.
- **Pull requests** — keep them small and focused; run `make test` and
  `make evals` before submitting and paste the gate output in the PR
  description. New behaviour needs a test; a changed loop exit or
  guardrail needs an eval case.
- **No real plant data, ever.** Cases, SOPs, and histories in this
  repo are synthetic. Do not contribute data copied from a real
  facility, vendor manual, or employer — write a fictional equivalent.

By contributing you agree your work is licensed under Apache 2.0.
